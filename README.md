# brayzenbusiness/.github

Org meta repository for **[brayzenbusiness](https://github.com/brayzenbusiness)**.

This repo holds organization-level files that are not tied to a single product repo:

| Path | What it is |
| ---- | ---------- |
| `profile/README.md` | Org profile — shown on the org page (to the public if this repo is public; visible to org members while private) |

Currently private — matching the org's private product stage. If the org decides to
open a public presence, flip this repo to public and the org profile renders on the
org page automatically.

Future org conventions (issue/PR templates, `CODEOWNERS`, dependabot config) land here,
not in individual product repos.
